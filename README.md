## ✨ Overview

**Venn Engine** is an interactive web application designed to help students
understand and work with **sets and set algebra**.

Instead of solving set expressions manually and drawing Venn diagrams by hand,
Venn Engine performs the computation directly in the browser.

Simply enter your sets, write an expression such as:
